기본 설정

이 브라우저에만 저장됩니다
https://script.google.com/macros/s//exec
노란 칸에 배포 ID만 넣거나, 구글이 준 주소 전체를 붙여 넣어도 알아서 나눠 담습니다. 비워 두면 이 브라우저에만 저장되는 연습 모드입니다. 교사는 이 칸을 채울 필요가 없습니다(링크로 자동 입력).
https://.github.io//
예: 아이디가 hakseong-msl, 저장소가 plan이면 → https://hakseong-msl.github.io/plan/. 주소 전체를 붙여 넣어도 됩니다. 아래 '교사용 링크'가 이 주소로 만들어집니다.
앱스 스크립트 코드의 KEY와 같은 값. 교사에게 보내는 링크에 함께 들어갑니다.
코드의 ADMIN_KEY와 같은 값. 이 브라우저에만 저장되고 교사 링크에는 들어가지 않습니다. 맞게 넣으면 담당자 탭이 열립니다.
확인 전
시트에 연결되면 서버가 열쇠를 보고 권한을 정합니다. 연습 모드에서는 모든 탭이 열립니다.
여기에 입력한 이름이 문서 오른쪽 위 상자와 모든 출력물에 쓰입니다.
앱 화면에만 쓰입니다. 추출되는 한글 문서는 공식 문서이므로 로고 없이 원래 서식 그대로 나옵니다.
정해 두면 교사 화면과 현황 화면이 그 학기 과목만 보여 줍니다.
문서 오른쪽 위 상자와 학운위 안건의 제안 부서에 쓰입니다.
.hwpx는 한글에서 바로 열려 그대로 편집·결재할 수 있습니다. 열리지 않는 환경이면 .doc으로 바꿔 받으세요.
학교명·부서명·과목 자료는 이 브라우저에만 저장됩니다. 파일 자체에는 들어 있지 않으니, 다른 선생님이 같은 파일을 열면 빈 상태로 시작합니다. 확인하려면 시크릿 창으로 열어 보세요.

처음 한 번만 하는 준비

약 10분
주소가 두 개 필요합니다. ① 자료 저장소 주소(앱스 스크립트 웹 앱 URL)는 자료가 오가는 곳이고, ② 교사용 접속 주소(깃허브 Pages 주소)는 선생님들이 이 화면을 여는 곳입니다. 둘을 넣으면 ③ 교사용 링크가 자동으로 만들어집니다.

  1. 구글 스프레드시트를 만들고 1행에 항목명을 붙여 넣습니다

    이 시트가 우리 학교 자료가 모이는 곳입니다. 새 스프레드시트의 A1 칸을 클릭한 뒤 아래를 그대로 붙여 넣으면 한 줄에 채워집니다.

    
          
          
    이미 쓰던 시트가 있다면 그대로 두세요. 새 코드가 빠진 항목(year, rev)을 맨 끝에 스스로 붙이고, 학생 명단은 대상자명단 시트를 따로 만들어 옮깁니다(담당자가 처음 접속할 때).
    
        
    2. 
        
  2. 
          
    앱스 스크립트에 코드를 붙여 넣고 '배포'합니다 → ① 주소를 얻습니다
    
          
    '배포'는 이 화면이 아니라 구글 시트 쪽에서 하는 일입니다.
    
          
      
            
    1. 스프레드시트 메뉴 확장 프로그램 → Apps Script를 누릅니다.
      2. 
            
    2. 편집기의 기존 코드를 모두 지우고 아래 코드를 붙여 넣은 뒤, 맨 위 KEY(교사 열쇠)와 ADMIN_KEY(담당자 열쇠)를 서로 다른 값으로 적고 저장(Ctrl+S)합니다.
      3. 
            
    3. 오른쪽 위 파란 배포 단추 → 새 배포 → 톱니바퀴에서 유형 웹 앱 → 실행 사용자 나, 액세스 권한 모든 사용자 → 배포.
      4. 
            
    4. 처음이면 권한을 묻습니다. 액세스 승인 → 계정 선택 → 고급 → (프로젝트)로 이동 → 허용을 누르세요. 내가 만든 코드라 뜨는 정상 경고입니다.
      5. 
            
    5. 마지막 화면의 웹 앱 URL(…/exec로 끝남)을 복사해 위 ① 자료 저장소 주소에 붙여 넣고, 같은 열쇠를 교사 열쇠·담당자 열쇠 칸에 넣은 뒤 설정 저장 → 연결 확인.
      6. 
          
    
          
    나중에 코드를 바꿀 때는 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포. 이렇게 하면 ① 주소가 바뀌지 않습니다. ('새 배포'를 또 누르면 주소가 새로 생기니 주의)
    
          
    
          
        
    3. 
        
  3. 
          
    이 화면 파일을 깃허브에 올립니다 → ② 주소를 얻습니다
    
          
    깃허브에서 저장소를 하나 만들고, 이 파일 이름을 index.html로 바꿔 올린 뒤 Settings → Pages에서 Branch를 main / (root)로 저장합니다. 1분쯤 뒤 그 화면 위쪽에 https://아이디.github.io/저장소이름/ 주소가 나타납니다. 이것을 위 ② 교사용 접속 주소에 넣으세요.
    
          
    새 판의 화면 파일을 받으면 그 저장소의 index.html만 바꿔 올리면 됩니다. ①, ② 주소는 그대로입니다.

  4. 
          
    작성 안내 탭을 먼저 채웁니다
    
          
    교사에게 링크를 보내기 전에 작성 안내 탭에서 항목별 작성 요령과 예시 문구를 만들어 두세요. 배포 뒤에도 담당자가 언제든 고칠 수 있습니다.
    
        
    5. 
        
  5. 
          
    ③ 교사용 링크를 복사해 메신저로 보냅니다
    
          
    ① + ② + 교사 열쇠·학교명·학년도를 합쳐 자동으로 만든 링크입니다. 교사가 한 번 열면 설정이 그 브라우저에 저장되고 주소창에서는 설정 부분이 곧바로 지워집니다. 담당자 열쇠는 들어가지 않습니다.

  6. 
          
    이미 만든 계획서나 편제표를 올립니다
    
          
    담당자 현황 탭에서 계획서 파일 불러오기(.hwpx) 또는 편제표 엑셀 불러오기로 과목을 만들어 두면, 누가 아직 안 냈는지 상태판에 바로 보입니다.

알아 두면 좋은 것

    

      
교사에게 안내할 문장 — 주소 접속 → 내 과목 선택 → 예시로 빈 칸 채우기 → 우리 과목에 맞게 손보기 → 제출하기. 로그인도 파일 첨부도 없습니다.

      
담당자가 화면에서 고친 내용은 교사가 다시 열었을 때도 그대로 보입니다. 보완이 필요하면 보완 요청으로 되돌려 두면 교사 화면 맨 위에 사유가 뜹니다.

      
학생 이름이 들어가는 대상자 명단은 개인정보입니다. 명단은 대상자명단 시트에만 저장되고, 교사 화면에는 자기가 고른 과목의 명단만 내려갑니다. 스프레드시트 자체는 담당자만 편집하도록 공유를 제한하고, 학년도가 끝나면 대상자·이수 점검 → 학년도 명단 일괄 삭제로 지우세요.
